# Hi, I'm PulseHabour 👋

I build tooling for the RAGE engine and the FiveM/Cfx ecosystem — file format
explorers, native reference tools, and the small utilities that make modding
less painful.

## 🔧 Public projects

- **[NativeCheck](https://github.com/PulseHabour/NativeCheck)** — a quick browser-based reference for looking up RAGE natives.
- **[NativeViewer](https://github.com/PulseHabour/NativeViewer)** — a Python companion for browsing native definitions.
- **[CfxRun-Resource](https://github.com/PulseHabour/CfxRun-Resource)** — the server-side resource for CfxRun, for launching straight into Cfx servers.

## 🚧 In the works

- **YARGE** — *Yet Another RAGE Editor.* A cross-platform (Windows + macOS) RPF
  explorer and world editor for RAGE-engine games, built clean-room from public
  format specifications. Pre-alpha, not public yet.
- **FiveM Stats** — server statistics tracking, Node + Postgres.
- **LuminHub** — a small Python service with TLS.
