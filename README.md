# pulsehabour.github.io

Source for [pulsehabour.github.io](https://pulsehabour.github.io/).

Plain static HTML — no build step, no Jekyll. Everything under `site/` is published
as-is by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on every push
to `main`.

To change the site, edit `site/index.html` and push.

## Do not delete

`site/google6d6eb9d1c0def92c.html` is the Google Search Console ownership proof for
this site. Google re-checks it periodically and drops verification if it disappears,
so leave it in place even though nothing links to it.
